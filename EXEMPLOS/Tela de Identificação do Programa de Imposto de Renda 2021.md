**Problema:** Fazer uma auditoria profunda de usabilidade na interface de "Identificação do Contribuinte" do software do Imposto de Renda 2021 de forma rápida, sem custo com laboratórios e sem recrutar usuários finais reais.

**Conceito utilizado:** Método de Inspeção por Percurso Cognitivo (_Cognitive Walkthrough_) baseado na simulação estruturada do modelo mental de primeiro uso do usuário.

**Solução:** O especialista assume o papel de um contribuinte iniciante e varre minuciosamente as telas passo a passo, aplicando **quatro perguntas ergonômicas cruciais** a cada elemento da interface:

1. _O usuário perceberá os radio buttons de seleção do tipo de declaração localizados no topo da tela?_
2. _O usuário perceberá e entenderá os pequenos ícones de interrogação que fornecem textos de ajuda contextuais?_
3. _O usuário compreenderá que deve preencher os campos de data de nascimento e título de eleitor utilizando apenas caracteres numéricos?_
4. _O usuário saberá identificar imediatamente quais campos são de preenchimento obrigatório no sistema?_
5. _O usuário compreenderá o campo "Tipo" e entenderá que deve clicar na seta adjacente para abrir o menu de opções disponíveis?_
6. _O usuário perceberá e confiará que suas informações digitadas são gravadas de maneira automática pelo sistema sem a necessidade de um botão físico de "salvar"?_
7. _O usuário compreenderá o ícone de alerta triangular vermelho, sabendo diagnosticar o que está incorreto para restabelecer a digitação certa?_
8. _O usuário conseguirá interagir com o menu lateral e entenderá a lógica espacial para navegar e transitar entre as fichas do sistema?_

**Resultado:** Emissão de um relatório de auditoria detalhado, listando de forma exata todos os desvios de usabilidade identificados na tela, juntamente com recomendações ergonômicas imediatas de correção.

**Por que essa solução funciona:** O Percurso Cognitivo funciona porque obriga o especialista a se despir de seu conhecimento avançado sobre o sistema para experimentar as telas a partir de uma perspectiva ingênua de primeiro uso, antecipando falhas antes de o software ser distribuído.

**O que preciso aprender com esse exemplo:** As 4 perguntas essenciais do Percurso Cognitivo avaliam se o usuário **tentará realizar a ação correta**, se ele **verá o elemento na interface**, se ele **associará o elemento à ação correta** e se ele **compreenderá o feedback de progresso** fornecido após a ação.
